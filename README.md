# 小车遥控器 1.2

**当前新版为 App 2.0，录制和自动执行已移到 ESP。最新使用方式见 [BOARD_MOTION.md](BOARD_MOTION.md)。下文保留1.2版本记录。**

连接 ESP32-S3 小车（Control-Car），横屏双指控制行走和转向。油门表示 PWM 占空比，不是测量车速。协议及接线见 D:/c-project/Control_car/README.md。

## 安装与连接

安装 CarRemote-debug.apk。打开 App 会主动请求连接 Control-Car（默认密码 car123456），所有控制请求固定通过该小车网络发送，不再取任意一个 Wi-Fi 网络。

Android 10 及以上使用系统指定网络连接接口。首次允许连接提示；以后系统可记住对该热点的授权。Android 13 及以上需要“附近设备”权限，Android 6～12 需要定位权限；部分手机还需要开启系统定位和 Wi-Fi。拒绝或超时后可点“连接小车”重试。Wi-Fi 断开后自动尝试重连，自动动作不会恢复。旧系统使用保存的指定热点进行连接。

手机的系统网络选择和厂商策略仍可能要求确认。App 不能绕过系统授权静默切换任何 Wi-Fi。进入后台取消自动动作并发送停止；保留网络请求以兼容系统的连接确认窗口，关闭页面时释放网络请求。固件原有断连停车和800毫秒指令超时停车仍有效。

## 轨迹返回

1. 通信正常后点“轨迹录制”，再手动驾驶。
2. 点“结束录制”，等待小车确认停车，按钮变为“开始执行”。
3. 点“开始执行”倒序执行记录，反转行走方向，保持左右转向和原油门。
4. 等待或执行途中，按其他控制按钮、操作油门，立即清除本次轨迹并接管；执行完成清除轨迹并停车。

录制、发送和执行共用单个后台流程。控制变化约每10毫秒检查一次，保持状态时每150毫秒刷新指令。以请求和成功响应的中点估算小车应用指令的时刻，记录实际成功发送的状态与持续时间；回放逐段等待成功响应，避免短段被原先的150毫秒界面轮询跳过。网络响应不是电机位置反馈，时间估计仍有误差。

“返程校准”分别保存返程前进和倒车的时长倍率（50%～200%，默认100%）。先用短直线测试：返程走短了调大，对应方向走过头调小。倍率只影响轨迹返回，不改变技能。轮胎打滑、机械间隙、弹簧转向回正延迟和电量变化仍会造成偏差，不能保证精确回到出发点；精确定位需要轮速、转角或外部位置反馈。

## 技能录制与技能库

点“技能录制”，操作小车，再点“结束并保存”，等待停车确认后输入名称。技能记录行走方向、左右转向、油门、刹车、停车以及各状态持续时间。技能库按原顺序和原油门执行，可重复使用；中途手动操作立即取消本次执行，已经保存的技能仍保留。

最多保存32个技能，名称不能重复且最多24字。技能保存在手机本地，关闭、重新打开 App 后仍保留；可在技能库删除。单次录制最长60秒，超时、通信失败、进入后台会取消本次未完成录制或执行。录制时没有行驶动作的记录不保存。

## 构建与验证

运行 build-apk.ps1，生成并校验 CarRemote-debug.apk。优先使用 Android Studio 的默认调试签名，便于覆盖本机同签名旧版；仅在默认密钥不存在时使用项目的备用调试密钥。签名不同的已安装版本不能直接覆盖。

运行 tests/run-engine-tests.ps1 验证动作引擎（12组场景）、多指按键归属和真实本地 HTTP 请求/响应。测试覆盖旧失败不能覆盖新按键、松手优先、短暂抖动、持续失联停车、录制作废后继续手动控制，以及响应消费和连接复用。

tests/device/SkillStoreInstrumentation.java 使用独立测试数据，在两次独立进程中验证技能保存、名称/转向/行走/油门/时长恢复和删除，不发送行驶命令。

## 1.2 遥控稳定性修复

- 手动遥控遇到短暂请求失败，600毫秒宽限期内补发最新指令，不清空仍按住的方向，也不把旧请求重新压回队列。松手、换方向始终优先。持续失联后清理旧动作并停车，恢复后不自动续跑。
- 录制遇到一次未确认响应即作废，避免保存不可信的轨迹；短抖动时保留当前手动操作。技能回放和自动返回遇到失败仍立即取消并停车。
- 主线程提示检查意图版本，防止迟到的失败通知清除用户刚按下的新方向。
- 完整读取并关闭 HTTP 响应，再回收连接；响应必须为小车的 OK。HTTP 超时和真实 Wi-Fi 断开分开处理。
- 状态栏固定单行，文字没变化不重复刷新；按键按 pointerId 独立处理松手和触摸越界，避免布局变化和第二根手指误释放第一根手指。页面可见时保持亮屏。
- 点击连接重试时，如果小车 Wi-Fi 仍连接，不主动拆掉此连接。迟到的旧网络断连回调不能清除新网络。

本地 HTTP 连接复用测试在电脑 Java 环境运行；手机 Wi-Fi 波动、真实触摸和车辆响应仍需实机验证。
